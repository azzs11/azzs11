I'm [**Akchhya**](https://www.linkedin.com/in/akchhya-singh11/), a software engineer and researcher in Bengaluru working on data, retrieval and ranking.

I'm currently building [HeritageRec](https://github.com/azzs11/Heritage_Doc_Recomm_Sys), a knowledge-graph search engine for Indian heritage documents (published at ICICACS 2026), and finding out how many ways history can spell the same king.

I like building things that are useful, occasionally cute, and always benchmarked.

When I'm not *engineering*, you can find me running a marathon, reading a novel, writing on Medium or binging my fav show.
